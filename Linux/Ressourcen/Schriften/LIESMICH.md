# Inter

Die Schrift der Oberfläche, mitgeliefert statt vom System erwartet.

**Warum sie beiliegt.** Auf dem Mac ist die Schrift SF Pro, und die gibt es
nur dort. Inter ist ihr nächster Verwandter — gleiche Bauart, gleiche
Strichstärke, offene Lizenz. Auf einem Linux-Rechner ist sie oft schon
installiert; unter Windows nie, dort fiele die Oberfläche auf Segoe UI zurück
und sähe deutlich anders aus als auf dem Mac. Da alle Plattformen gleich
aussehen sollen, bringt die App sie selbst mit.

Zwei Dateien reichen: `InterVariable.ttf` deckt alle Strichstärken ab, die
kursive Fassung die Auszeichnungen.

**Lizenz:** SIL Open Font License 1.1, siehe `OFL.txt`. Weitergabe erlaubt,
auch mitgeliefert in einem Programm; der Lizenztext muss dabeiliegen, und
genau dafür ist er hier.
